
Lektion 1: HTML (Hyper Text Markup Language)

    Auszeichnungssprache mit der die Struktur einer Website beschrieben wird.

<!DOCTYPE html> Teilt dem Browser mit, dass es sich um ein HTML5-Dokument handelt.

Textdesign:
    <h1>    wichtigste Überschrift
    <h2>    Unterabschnitt
    <h3>    Unter-Unterabschnitt
    <p>     Absatz
    <a>     Link
    href    Attribut: Ziel eines Links
    <br>    Zeilenumbruch

Links:
    id -> Sprungmarke: eindeutige Kennzeichnung eines Elements
    <h3 id="installation">1. Installation</h3>
    <a href="#installation">1. Installation</a>

Bilder:
    <img src="screenshot.png" alt="Screenshot des Ren'Py Image Positioning Tools">
    <img    Bild
    src     source (Quelle)
    alt     Beschreibung des Bildes:    Wird angezeigt, wenn das Bild nicht
                                        geladen werden kann oder der Vorlesemodus aktiv ist.

    style="max-width: 100%; height: auto; display: block;"> (innerhalb von figure): block: Sorgt für eine saubere Anordnung von Bild und Bildunterschrift.

Listen:
    <ul>    ungeordnete Listen, Aufzählungspunkte
    <ol>    geordnete Liste, Nummerierung
    <li>    Einzelner Listenpunkt

Verschachtelung:
    <ul>
        <li>Installation</li>
        <li>Bedienung
            <ul>
                <li>Image Move Menu</li>
                <li>Bild laden</li>
                <li>Position verändern</li>
            </ul>
        </li>
    </ul>

    <small> Eine Schriftgröße kleiner

    target="_blank" Link es wird in einem neuen Tab öffnen
    rel="noopener noreferrer"   rel beschreibt die Beziehung zwischen Website und
                                Linkziel
    noopener    Schutz vor Manipulation: ohne kann eine neu geöffnete Seite über Java-
                Script auf die ursprüngliche Seite zugreifen.
    noreferrer  HTTP-Referer (Herkunftsinformationen) werden nicht übertragen.

Tabellen:
    <table> – Tabelle
    <tr> – Tabellenzeile
    <th> – Tabellenüberschrift
    <td> – Tabellenzelle

text-decoration: none;  Entfernt den Link-Unterstrich

Formulare (Beispiel mit einem Suchfeld.):
    <form>      Umschließt das Formular.
    <label>     Beschriftet das Eingabefeld.
    <input>     Erstellt ein Eingabefeld.
    <button>    Erstellt einen Button.
    type="text" bedeutet, dass der Besucher normalen Text eingeben kann.
    id="search" gibt dem Eingabefeld eine eindeutige Kennung.
    for="search" verbindet die Beschriftung mit genau diesem Eingabefeld.
    type="submit" kennzeichnet den Button als Absende-Button.

    <form onsubmit="return false;"> Verhindert, dass das Formular tatsächlich abgeschickt wird (Übergangslösung)

Suche mit JavaScript:
    <script>
    1.   function searchWebsite() {
    2.      let searchTerm = document.getElementById("search").value;
    3.      alert("Du suchst nach: " + searchTerm);
        }
    </script>

    Ablauf:
        1. Funktion Namens searchWebsite() erstellt.
        2. Den Inhalt des Suchfeldes auslesen:
            document.getElementById("search")
                sucht das HTML-Element mit der ID search.

            .value
                liest den eingegebenen Text aus.

            alert("Du suchst nach: " + searchTerm);
                alert() öffnet ein kleines Meldefenster im Browser.
                + verbindet den Text mit dem eingegebenen Suchbegriff.

JavaScript:
    Grundlagen:
        let Deklariert eine Variable.
        == Konvertiert Datentypen bei Bedarf vorher.
        === Konvertiert nicht.

    Buttons:
        type="submit"   Lädt die Seite neu oder triggert ein Form-Submit-Event.
        type="button"   Neutraler Klick-Button der mit einer Logik belegt werden
                        muss.

    Suche:
        .toLowerCase()  Wandelt Text in Kleinbuchstaben um.
        getElementsByTagName("tr")  Sucht alle Tabellenzeilen.
        .textContent    Liest den Text eines HTML-Elements aus.
        .includes()     Prüft, ob ein Text einen bestimmten Begriff enthält.
        .style.display = "none" Blendet ein Element aus.
        .style.display =    "" Element nimmt wieder den Standardwert an, bzw.
                            wird nach "none" wieder sichtbar.
        .trim() Entfernt Leerzeichen am Anfang und Ende einer Eingabe.

    Sprung:
        firstMatch  Speichert die erste gefundene Tabellenzeile.
        null        Bedeutet zunächst, dass keine Treffer gefunden wurden.
        scrollIntoView()    Scrollt die zum gefundenen Website zum gefundenen
                            Element.

        behavior: "smooth"  Sorgt für ein sanftes Scrollen.
        block: "center"     Positioniert das Ergebnis ungefähr in der
                            Bildschirmmitte.

    CSS:
        even Wählt gerade Elemente aus.
        odd Wählt ungerade Elemente aus.
        nth-child() Zählt die Elemente innerhalb ihres übergeordneten Elements.

        Scrollbar:
            /* 1. Die Gesamtbreite der Scrollleiste */
            ::-webkit-scrollbar {
                width: 10px;
            }

            /* 2. Der Hintergrund der Schiene (der Kanal, in dem der Schieber läuft) */
            ::-webkit-scrollbar-track {
                background: #2c3034; /* Passend zur Tabelle */
            }

            /* 3. Thumb im Normalzustand */
            ::-webkit-scrollbar-thumb {
                background: #555555; /* Dezentes Grau */
                border-radius: 5px;  /* Abgerundete Ecken */
            }

            /* 4. Hover */
            ::-webkit-scrollbar-thumb:hover {
                background: #2d9d1d; /* Zum Beispiel dein schöner grüner Akzent-Ton! */
            }

        Bild auf die Breite des Fensters anpassen:
            style="max-width: 100%; height: auto; display: block;"


    Bild beim Klick vergrößern:
        onclick="openModal(this)": Jedes Bild, das du so markierst, übergibt sich beim Anklicken selbst an die JavaScript-Funktion. Du kannst diese Klasse (zoomable-img) und den Befehl also beliebig oft für unterschiedliche Bilder auf deiner Seite verwenden – es wird immer dasselbe Overlay genutzt!

        display: flex + justify-content/align-items: Zentriert das vergrößerte Bild perfekt auf dem Bildschirm, egal wie groß der Monitor ist.

        cursor: zoom-in / zoom-out: Gibt dem Nutzer sofort visuelles Feedback, dass hier eine Zoom-Aktion stattfindet.
